# NetStim website redesign

Static website mockup, source audit, design notes, and content comparisons.

## Preview

Open `mock/index.html` in a browser, or run `python3 -m http.server 8876 --bind 127.0.0.1 --directory mock` and visit http://localhost:8876.

## Project files

- `mock/`: website and local assets; see `mock/README.md` for coverage and verification limits.
- `design/`: visual direction notes.
- `review/`: content comparisons, source snapshots, and review scripts.
- `content-audit.md`: source audit.
- `sources/`: reference material, when available.

The local ZIP export is retained but excluded from version control because it duplicates the website files.
